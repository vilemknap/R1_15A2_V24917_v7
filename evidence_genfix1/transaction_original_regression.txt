Recovery ownership review
-------------------------
- Planned recovery rows are copied before the first possible COM parameter write.
- Recovery rows survive cheap parameter-only restoration and cover the union of
  attempted attributes/zones, independently of applied_rows.
- demand_dirty becomes true before attempting native assignment. It remains true
  across rejected trials and parameter-only restoration.
- A known pre-write GENERATION_GATE rejection can release recovery ownership only
  when no assignment has occurred and require_parent proves exact parent equality.
- Full rollback releases ownership only after the authoritative rollback returns
  and the diagnostic hash matches the parent.
- Accepted trials release ownership only after acceptance and publication succeed.
- The outer failure handler also protects planning/checkpoint/bookkeeping exits.
- rollback_started prevents an automatic second full rollback if the first one fails.
- No acceptance threshold, matrix fingerprint, operation hash, or model guard was removed.
